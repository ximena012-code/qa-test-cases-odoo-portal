# QA Test Cases — Odoo Portal (Service Reports)

Portfolio de **Quality Assurance** con casos de prueba funcionales para un listado tipo portal Odoo (Service Reports / Field Service).

## Qué incluye
- Casos de prueba en formato Gherkin-light / pasos numerados
- Matriz pass/fail de ejemplo
- Cobertura: listado, búsqueda, filtros, orden, paginación, PDF, i18n EN/ES, permisos por rol (DSP / TEC / PRT)

## Cómo leerlo
1. Abre `test-cases/TC-SERVICE-REPORTS.md`
2. Revisa `matrices/matriz-resultados.md`
3. Carpeta `evidence/` para capturas o notas de evidencia

## Stack / contexto
- Plataforma: Odoo 18 portal
- Tipo de pruebas: funcionales, regresión, validación de criterios de aceptación
- Roles: Despachador (DSP), Técnico (TEC), Portal sin FSM (PRT)
